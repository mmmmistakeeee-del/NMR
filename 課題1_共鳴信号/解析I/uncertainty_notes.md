# 不確かさを出す解析

実行方法と考え方を初めて読む場合は、まず [README.md](README.md) を参照。このファイルは今回の数値と方法の詳しい記録。

`nmr_uncertainty.py` は、前段の有限変調Voigtモデルと相関ノイズモデルを用いて、パラメータの不確かさを出力する。

## 今回の計算結果（2026-10-28）

相関する相対振幅成分と背景電圧雑音から300系列を生成した。平均波形と選択したノイズモデルの再フィットは300/300回成功した。

| 量 | 元データの推定値 | ブートストラップ標準偏差 | 2.5–97.5%の再推定値の範囲 |
|---|---:|---:|---:|
| 共鳴周波数 (MHz) | 16.01062276 | 0.00002145（21.45 Hz） | 16.01058295–16.01066271 |
| 観測信号の山と谷の間隔 (kHz) | 2.37374 | 0.09632 | 2.22479–2.60349 |
| ローレンツ半値半幅 (kHz) | 0.48394 | 0.14432 | 0.26209–0.88368 |
| 静的ガウス分布の幅 (kHz) | 1.03486 | 0.20149 | 0.41728–1.13033 |
| 変調の片側周波数振幅 (kHz) | 0（微小変調極限） | 0.63192 | 0–1.49645 |
| 背景電圧雑音の標準偏差 (元データ単位) | 0.04560 | 0.00106 | 0.04345–0.04762 |

変調幅は139/300回（46.3%）でゼロ境界に達した。幅を単純な対称誤差で解釈することは適切でない。特に上表の幅の百分位範囲は、校正された95%信頼区間ではなく、仮定したモデルのもとでの再推定分布の範囲である。

共鳴周波数のブートストラップ平均の偏りは約-1.11 Hz。一方、相対振幅ノイズ強度の元推定値8.31%に対し、再推定分布の平均は約5.52%、標準偏差は約2.16パーセントポイントで、偏りが大きかった。相関係数も再推定時の不安定性が大きい。相関成分の振幅がゼロになった3試行ではrhoを欠損として扱い、rhoのみ297試行を集計した。

各点の値ではなく平均曲線の不確かさを表す図と、各パラメータの分布図も保存した。全ての標準偏差欄が、保存された試行データからddof=1で計算した標準偏差と一致することを確認した。

## 実行

保存済みの300回分から、再フィットせずに結果を表示・集計する場合:

```powershell
python -B nmr_uncertainty.py --summarize-only
```

日本語の列名の結果表 `*_uncertainty_parameters_ja.csv` も保存する。

このフォルダで、既存の平均波形・ノイズ解析の結果から計算する場合:

```powershell
python -B nmr_uncertainty.py --replicates 300 --workers 4
```

データから平均波形・ノイズ解析も実行し直す場合:

```powershell
python -B nmr_joint_noise.py 20261020_KITtest01.dat --bootstrap 300 --workers 4
```

乱数シードは既定で20261028。`--seed` で指定できる。各試行は独立のシードを用い、ワーカー数によらず同じ模擬データになる。元データと保存された解析結果が一致することを確認してから実行する。

## 計算内容

1. 推定済みの平均波形に、背景電圧雑音と、選択された信号依存の相関雑音を加えた模擬データを作る。元と同じ周波数点・測定順序を用いる。
2. 中心、ローレンツ幅、ガウス分布幅、変調振幅、全体振幅、背景切片・傾きを再フィットする。複数の初期値に加え、微小変調極限とガウス幅ゼロの境界も比較する。
3. 選択されたノイズモデルのパラメータも再推定する。モデルの種類そのものの選び直しは行わない。
4. 再推定値の分布から、標準偏差、中央値、バイアス、16/84パーセンタイル、2.5/97.5パーセンタイル、パラメータ相関を計算する。

`bootstrap_SD` は再推定値の標本標準偏差（ddof=1）。これはモデルを仮定した推定量の標準誤差・標準不確かさの見積もりであり、シミュレーション回数の平方根では割らない。300回から3000回に増やすことは不確かさの推定を安定させるが、実験自体の情報量を増やすものではない。

標準不確かさという用語の参考: [JCGMの国際計量用語集](https://www.iso.org/sites/JCGM/VIM/JCGM_200e_FILES/MAIN_JCGM_200e/02_e.html)。本プログラムが扱うのは、仮定した平均・ノイズモデルに条件を付けたパラメトリック・ブートストラップであり、全ての系統要因を含めた不確かさ予算ではない。

## 出力の読み方

- `*_uncertainty_parameters.csv`: 元データの推定値、単位、標準偏差、分布の区間、バイアス、成功数、注意事項。
- `*_uncertainty_samples.csv`: 各試行の推定値と成功・失敗の記録。10試行ごとに保存。
- `*_uncertainty_correlation.csv`: 再推定値の相関行列。
- `*_uncertainty_metadata.json`: 乱数シード、試行数、元データのハッシュ、境界に達した割合、適用範囲。
- `*_uncertainty_distributions.png`: 共鳴周波数・山と谷の間隔・ローレンツ幅の分布と、変調幅とガウス幅の交換関係。
- `*_uncertainty_mean_band.csv/png`: 平均フィット曲線の不確かさ。個々の測定値の散らばりを示す予測区間とは異なる。

`static_sigma_kHz` は共鳴周波数分布そのものの幅で、その量の推定の不確かさは同じ行の `bootstrap_SD`。また `white_SD_at_ref` は電圧雑音の標準偏差で、その推定の不確かさは別に `bootstrap_SD` に出る。「ノイズの大きさ」と「その大きさの推定の不確かさ」を区別する。

`observed_peak_to_peak_kHz` は背景を除いた観測信号モデルの山と谷の周波数間隔。`absorption_Voigt_FWHM_kHz` は有限変調を加える前のVoigt吸収曲線の半値全幅であり、両者を区別する。

## 条件と限界

- 生成に使う平均・ノイズのパラメータは、元データの推定値に固定したプラグイン法。再推定のばらつきを評価するが、モデル選択や未知の系統要因まで積分したものではない。
- 変調振幅がゼロ境界にあることと、幅の交換関係のため、幅の分布は非対称になり得る。これらに `推定値 ± 標準偏差` を機械的に適用しない。
- 2.5–97.5%の欄はブートストラップ分布の中央95%範囲。特に境界・識別の弱いパラメータについて、真値を95%で覆うことを検証した信頼区間とは呼ばない。
- 選択されたノイズモデルで固定された成分は、標準偏差がゼロでも実際の不存在が証明されたことにはならない。
- 相関雑音の振幅がゼロになった試行ではrhoを識別できないため、rhoを欠損値とし、その集計から除く。rhoの区間は非ゼロ振幅を推定できた試行に条件を付けたものとなり、`n_success`も確認する。
- `bootstrap_bias` が標準偏差に比べて大きい量は、対称な「±標準偏差」だけでは結果を十分に表せない。ノイズ強度・相関の推定にもこの傾向があり、元の推定値、再推定分布の中央値、偏りを併せて見る。
- 系統的な波形のずれが相関雑音として表現されている可能性は残る。時定数、周波数校正、変調磁場の校正、有限周波数のBloch応答の不確かさは含まない。
- 少数試行の百分位点は不安定。既定の300回は探索的な計算で、精密な区間端点が必要なら試行数を増やす。

## 数値検証

雑音生成器が想定した共分散を再現することを、独立した50000系列の模擬生成で確認する。波形の数値積分は粗密の比較を行い、必要な試行では再フィットする。失敗した試行は黙って除外せず記録し、平均波形の再フィット成功率が90%を下回る場合は集計を停止する。
