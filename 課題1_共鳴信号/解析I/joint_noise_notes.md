# 有限変調・共鳴周波数分布・残差ノイズの解析

初めて読む場合の実行方法・コードの案内は [README.md](README.md) を参照。このファイルは解析条件と数値の記録。

対象: `20261020_KITtest01.dat`。1250点、周波数はHz。元データは変更していない。

再実行（このフォルダで）:

```powershell
python -B nmr_joint_noise.py
```

## 平均波形

ローレンツ吸収と標準偏差 sigma のガウス分布を畳み込んだVoigt吸収について、正弦波磁場変調の基本波成分を計算した。変調は準静的と仮定し、出力は自由振幅と直線背景を含めて全1250点に非加重最小二乗で当てはめた。

内部周波数はkHz。gammaはローレンツ半値半幅、aは変調の片側周波数振幅。基本波をaで割った形を使用しており、a=0は微小変調極限の微分形を意味する。実験で磁場変調を行わなかったという意味ではない。

最小二乗解は微小変調極限にあり、gamma=0.48394 kHz、sigma=1.03486 kHz、中心16.01062276 MHz。全体RMS=0.050689、共通の共鳴付近75点のRMS=0.064660。

ただし、aを固定して他のパラメータを再最適化すると、以下のようにほぼ同じ適合度が得られる。

| a (kHz) | gamma (kHz) | sigma (kHz) | 全体RMS | 共鳴付近RMS |
|---:|---:|---:|---:|---:|
| 0.0 | 0.48394 | 1.03486 | 0.050689 | 0.064660 |
| 0.8 | 0.49788 | 0.94336 | 0.050691 | 0.064700 |
| 1.0 | 0.52171 | 0.87457 | 0.050696 | 0.064805 |
| 1.3 | 0.59558 | 0.69202 | 0.050783 | 0.065999 |

0から1 kHzまでの変調幅の変更は、分布幅の変更によって大部分を補償できる。これは95%信頼区間などを意味する範囲ではない。単純な平均波形の適合度の比較である。

小さいaでは基本波/a = V' + (a^2/8)V''' + ... であり、変調は一次近似で分散a^2/4の追加の広がりに相当する。ガウス分布の広がりと交換しやすい理由を、この展開からも理解できる。

プロファイルはa=0から2 kHzを0.1 kHz刻みで計算した。図の N log(SSE/SSE_min) は独立・等分散誤差を仮定した参考尺度で、相関雑音に対応した信頼区間ではない。a>=1.8 kHzの一部ではgammaの探索下限0.02 kHzに達している。CSVにフラグを記録した。

## ノイズの条件付き比較

上の平均波形を固定し、背景を除く平均信号をs_i、その周波数微分をd_iとした。残差を

`r_i = e_i + sigma_j * d_i * U_i + sigma_g * s_i * G_i`

で表した。UとGは互いに独立な単位定常分散のAR(1)過程。相関モデルでは両者に共通のrhoを用いる。eは独立なガウス雑音で、その標準偏差の対数を周波数の一次関数とした。これは波形の左右で背景の散らばりが違うことを表す少数パラメータの近似である。

8候補を比較した。カルマンフィルターの予測誤差と予測分散から、分散の対数項を含む正規尤度を計算した。比較スコアは `2*NLL + 2*(ノイズのパラメータ数)`。平均波形を同時に尤度最大化していないので、条件付きの探索的指標としてのみ扱う。

| 残差モデル | 最小スコアとの差 |
|---|---:|
| 一定の独立電圧雑音 | 78.10 |
| 周波数で大きさが変わる独立電圧雑音 | 53.13 |
| 電圧雑音 + 独立な周波数揺らぎ | 48.97 |
| 電圧雑音 + 独立な相対振幅揺らぎ | 14.64 |
| 電圧雑音 + 独立な両成分 | 16.64 |
| 電圧雑音 + 相関する周波数揺らぎ | 40.86 |
| 電圧雑音 + 相関する相対振幅揺らぎ | 0.00 |
| 電圧雑音 + 相関する両成分 | 1.23 |

最小スコアのモデルの有効パラメータ:

- 共鳴付近の独立電圧雑音の標準偏差: 0.04560（元データの信号単位）
- 相対振幅成分の標準偏差: 8.31%
- 相対振幅成分の1測定点あたりの相関rho: 0.799
- 共鳴付近の生の残差の隣接相関: 0.569
- 同モデルで予測・標準化したイノベーションの共鳴付近の隣接相関: 0.199
- 共鳴付近の標準化イノベーションRMS: 0.929

相関は減るが完全には消えない。周波数揺らぎも加えたモデルとのスコア差は1.23にとどまり、周波数揺らぎがないことを示す結果ではない。相関する信号依存の残差を、相対振幅変動に似た成分で比較的よく表現できた、という範囲の結果である。

8.31%は実機の利得変動を直接測った値ではない。平均波形の非対称性、未導入の時間応答なども、この成分に取り込まれ得る。今回の推定では平均パラメータの不確かさを伝播していない。ノイズを導入して平均波形の残差RMS自体を小さくしたのではなく、残差の分散と相関を記述した。

## 検証と出力

- 有限変調Voigtの積分を、独立した基本波の数値積分と照合した。
- カルマン尤度・標準化予測誤差を、25点の密な共分散行列のCholesky分解による計算と照合した。
- 選択された最終平均波形を128点と256点の積分で照合した。最終解は微小変調極限の解析式に一致した。
- 共鳴付近の評価窓は生データの山と谷の中点16.010605 MHzから±5 kHzの共通75点。
- ±5/10/15/30 kHzでの平均波形の再フィットも保存した。この範囲で中心は16.0106221から16.0106230 MHz程度だが、この安定性は系統誤差の評価ではない。
- `*_profile.csv/png`: 幅の交換関係と適合度。
- `*_noise.csv`: 8候補の条件付きノイズ比較。
- `*_residuals.csv`: 各点の平均、残差、選択モデルの予測誤差など。
- `*_windows.csv`: フィット範囲依存性。
- `*_summary.json`: 最終パラメータ、仮定、探索範囲。
- `*_diagnostics.png`: 平均波形、残差と条件付き標準偏差、標準化予測誤差。

測定時刻がないためrhoは測定順序上の相関であり、秒単位の時定数に換算していない。掃引遅れ・有限変調周波数でのBloch応答・磁場変調の校正は今回のモデルに含めていない。したがってgammaをそのまま物質固有のT2に換算することはしていない。
