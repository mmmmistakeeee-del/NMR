# NMR解析：最初に読む案内

このフォルダでは、NMRの測定波形から**共鳴周波数・線幅・それらの不確かさ**を求めます。

現在のモデルは「ローレンツ型の吸収に、試料内の共鳴周波数のばらつきと磁場変調を加えた波形」です。平均波形をフィットした後、残差にノイズモデルを当てはめます。

## まず、今ある結果を確認する

このフォルダをターミナルで開き、次を実行します。

```powershell
python -B nmr_uncertainty.py --summarize-only
```

保存してある300回の再フィット結果を読み、画面に日本語で主要な結果を表示します。模擬測定をやり直す必要はありません。

最初に見るファイルは次の3種類です。実際のファイル名の先頭には測定データ名が付きます。

| ファイル名の末尾 | 分かること |
|---|---|
| `_uncertainty_parameters_ja.csv` | 日本語の結果表。推定値と標準不確かさを確認する |
| `_uncertainty_distributions.png` | 推定値のばらつき方、変調幅と周波数分布幅の交換関係を見る |
| `_uncertainty_mean_band.png` | フィットした平均曲線の不確かさを見る |

## 新しいデータを解析する

入力は、**周波数[Hz]と信号の2列**の数値ファイルです。空白やタブで区切ります。測定順序でノイズの相関を扱うため、現在のコードは周波数が厳密に昇順のデータを要求します。

```text
1.6010000E7    0.25
1.6010100E7    0.18
...
```

平均波形・幅の交換関係・ノイズ・不確かさまで一度に計算するには、次を実行します。

```powershell
python -B nmr_joint_noise.py 測定データ.dat --bootstrap 300 --workers 4
```

- `--bootstrap 300`：模擬測定を300回作り、毎回フィットする。
- `--workers 4`：4個の処理を並列で動かす。パソコンが重い場合は1や2にする。
- `--seed 20261028`：乱数の再現用番号。同じ番号なら同じ模擬データを作る。

前回の1250点・300回の不確かさ計算は、この環境で約10分でした。試行回数とパソコンの性能で変わります。

不確かさの計算を省いて、平均波形とノイズだけ調べる場合は `--bootstrap` を省きます。

```powershell
python -B nmr_joint_noise.py 測定データ.dat
```

平均波形・ノイズの解析が済んでいて、不確かさだけ計算し直す場合:

```powershell
python -B nmr_uncertainty.py 測定データ.dat --replicates 300 --workers 4
```

出力は入力データと同じフォルダに保存します。同じデータ名で再実行すると、対応する結果ファイルを更新します。`--summarize-only` も集計表と図を更新します。必要なライブラリはNumPy、pandas、SciPy、Matplotlibです。

## 何を計算しているか

処理の順序は次のとおりです。

```text
周波数・信号の測定データ
    ↓
平均波形を最小二乗でフィット
    ↓
幅の組合せを変え、同じ形を説明できる組合せを調べる
    ↓
残差 = 測定値 − 平均波形
    ↓
残差の大きさ・相関を表すノイズモデルを選ぶ
    ↓
平均波形 + 仮定したノイズから模擬測定を何回も作る
    ↓
毎回フィットし、パラメータの標準偏差と区間を求める
```

### 平均波形のパラメータ

まず、個々の場所の吸収をローレンツ型と仮定します。試料内の共鳴周波数がガウス分布でばらつくと、それらを足した吸収はVoigt型になります。さらに、磁場を正弦波で変調してロックインで検出したときの基本波成分を計算します。

背景も含めた式は、概略

\[
\hat y(x)=A\,S(x-c;\Gamma,\sigma_f,a)+b_0+b_1x
\]

です。`x` は基準周波数からの差[kHz]。`S` が変調後の波形です。

| 記号 | 意味 | 単位 |
|---|---|---|
| `c` | 基準からの共鳴中心のずれ | kHz |
| `Gamma` / `gamma` | ローレンツ吸収の半値半幅 | kHz |
| `sigma_f` / `sigma` | 試料内の共鳴周波数の分布幅 | kHz |
| `a` / `excursion` | 変調による共鳴周波数の片側の振れ幅 | kHz |
| `A` | 信号全体の倍率 | 信号単位 × kHz² |
| `b0` | 背景の切片 | 元データの信号単位 |
| `b1` | 背景の傾き | 信号単位/kHz |

**分布の幅 `sigma` と、その幅を推定する不確かさは別の量**です。例えば今回の結果は、分布幅の推定値が約1.035 kHz、その推定の標準不確かさが約0.201 kHzです。

`a=0` は微小変調の極限を表します。モデルは基本波を `a` で割って正規化しているため、実験で磁場変調を行わなかったという意味ではありません。

### ノイズモデル

背景にある電圧雑音に、必要なら次の成分を加えます。

| 成分 | どこで電圧のばらつきが大きくなるか |
|---|---|
| 周波数の揺らぎ | 平均波形の傾きが大きい場所 |
| 相対振幅の揺らぎ | 平均信号の絶対値が大きい場所 |

相関するモデルでは、前の点の揺らぎの一部を次の点へ引き継ぎます。その割合が `rho` です。測定時刻がないので、相関は「何点離れているか」で表します。

コードは8種類の候補を比較します。今回選んだのは、**背景電圧雑音＋相関する相対振幅成分**です。これは残差の表し方として選んだモデルであり、装置の利得変動を直接測定した結果ではありません。

### 不確かさ

模擬測定を300回作ると、例えば共鳴周波数の推定値も300個得られます。その標準偏差を、今回のモデルで見積もった標準不確かさとします。

\[
u(\theta)=\sqrt{\frac{1}{B-1}\sum_{b=1}^{B}(\hat\theta_b-\overline{\hat\theta})^2}
\]

`B` は模擬測定の回数。`theta` は中心周波数や線幅など、調べる量です。

この標準偏差をさらに `sqrt(B)` で割ることはしません。回数を増やすと**不確かさの見積もりが安定する**のであって、元の実験の情報量が増えるわけではないからです。

平均波形の残差RMSは、各点が曲線からどのくらい外れるかを表します。一方、ここで求める標準不確かさは、**中心周波数や幅の推定値がどのくらい変わり得るか**を表します。

## 結果表の読み方

| 英語CSVの列 | 日本語表の列 | 読み方 |
|---|---|---|
| `estimate` | 元データの推定値 | 実際の測定データに当てはめた値 |
| `bootstrap_SD` | 標準不確かさ_標準偏差 | 模擬測定からの再推定値の標準偏差 |
| `q16`, `q84` | 16/84パーセンタイル | 再推定値の中央68%の範囲 |
| `q025`, `q975` | 2.5/97.5パーセンタイル | 再推定値の中央95%の範囲 |
| `bootstrap_bias` | 再推定平均と元推定値の差 | 再推定値の分布が元推定値からどれだけずれたか |
| `n_success` | 集計できた回数 | その量を計算できた試行数 |

今回の共鳴周波数は `16.01062276 MHz`、標準不確かさは `0.00002145 MHz = 21.45 Hz` でした。

ローレンツ幅・周波数分布幅・変調幅は互いに補い合うため、推定値の分布が非対称になっています。これらは標準偏差だけでなく、区間と分布図も併せて見ます。特に幅の中央95%範囲は、真値を95%で覆うと検証した信頼区間ではありません。

この不確かさは、仮定した平均波形・ノイズモデルの下での計算です。周波数の校正誤差、掃引遅れ、変調磁場の校正誤差などは含んでいません。

## コードを読む順序

最初は `nmr_uncertainty.py` の次の関数を順に読むと、全体の流れを追えます。

| 関数 | 役割 |
|---|---|
| `run_uncertainty` | 不確かさ計算全体の入口。各処理を順に呼ぶ |
| `load_saved_analysis` | 元データと前段の解析結果を照合して読み込む |
| `run_bootstrap_refits` | 模擬測定と再フィットを繰り返す |
| `one_replicate` | 模擬測定1回分の具体的な処理 |
| `summarize_parameters` | 標準偏差・区間・偏りを計算する |
| `save_bootstrap_results` | 日本語表・数値表・図を保存する |
| `summarize_existing` | 保存済みの試行から集計だけやり直す |

平均波形の計算を詳しく読む場合は `nmr_joint_noise.py` の `modulated_voigt` → `fit_mean`、ノイズの計算は `fit_noise` → `innovations` を読みます。各関数に日本語で引数・単位・戻り値を記載しています。

コード内の短い変数名は、数値関数間の受け渡しで次のように使います。

```python
x = (測定周波数_Hz - 基準周波数_Hz) / 1000
q = [中心の差_kHz, ローレンツ半値半幅_kHz, ガウス分布幅_kHz, 変調片振幅_kHz]
beta = [信号の倍率, 背景の切片, 背景の傾き]
pred = モデルが予測する各点の値
residual = y - pred
```

| Pythonファイル | 現在の役割 |
|---|---|
| `nmr_joint_noise.py` | データから平均波形・幅の交換関係・ノイズを解析する入口 |
| `nmr_uncertainty.py` | 不確かさ計算と、保存済み試行の集計 |
| `nmr_physical_models.py` | 上の2本が使う基礎波形の数式。単独実行すると以前の4モデル比較 |
| `nmr_fit.py` | 参考：初期のローレンツ微分形だけの解析 |
| `nmr_compare.py` | 参考：初期のローレンツ型・ガウス型の比較 |

今回の詳しい数値・仮定・検証は `uncertainty_notes.md`、前段の幅とノイズの比較は `joint_noise_notes.md` に保存しています。
