# 測定日をまたぐ共鳴周波数の比較

2026年11月11日確認。ユーザーから、以前の測定と先週以降の測定でロックインアンプの設定は変更していないと確認された。具体的な設定値や磁石・試料の設置状態まで同一と確認できたわけではない。

## 同一座標の比較結果

元の `results/fit_results.csv` と最新日を採用した `results_with_additions/fit_results.csv` を照合した。同一座標で日付が変わる4点は、すべて x=4.5、旧測定が2026年10月27日、新測定が11月10日である。

| z | 10月27日の f₀ / MHz | 11月10日の f₀ / MHz | 新−旧 / kHz |
| --- | --- | --- | --- |
| 2.5 | 16.011364 | 16.021162 | +9.798 |
| 3.0 | 16.013387 | 16.022925 | +9.538 |
| 3.5 | 16.014430 | 16.023816 | +9.386 |
| 4.0 | 16.014821 | 16.024798 | +9.976 |

差の単純平均は +9.675 kHz、4点間の標本標準偏差は0.263 kHz。標準偏差は補正値の確定した不確かさではない。差の形式的なフィット標準誤差は39〜74 Hzで、観測された差はこれより大幅に大きい。ただし残差相関があるため、この標準誤差だけから厳密な有意水準を主張しない。

各データの全範囲フィット中心を基準に、同じ相対範囲 ±5 kHz で再フィットしても差は +9.763、+9.516、+9.388、+9.973 kHz。全範囲の結果との差は最大36 Hzで、約9.7 kHzの差はフィット範囲をそろえても残る。狭い範囲のフィットは感度確認用であり、本解析を置き換えない。

## 解釈と今後の扱い

- 同一座標でも日付に伴うほぼ共通の周波数上昇が見られる。結合したxz図の上下の段差には、この日付間のずれが大きく影響していると考えられる。現状の段差をそのまま空間的な磁場の境界と解釈しない。
- 比較しているのは共鳴中心周波数であり、検出電圧の背景オフセットとは別の量。現行フィットには定数・一次の背景項を含めている。
- ロックインの設定変更を原因とする説明は採用しない。磁場そのものの経時変化、試料・磁石の位置や座標原点の再現性、周波数系などは切り分け候補であり、この4点から原因を確定できない。
- 差は完全な定数ではなく最大約0.590 kHzの開きがある。また同一座標の比較はx=4.5に限られるので、全空間に一定の補正を適用できるとまでは確認できない。
- 11月4日にも同じ大きさのずれがあるかは、この10月27日対11月10日の比較だけでは確定できない。
- 最新日優先の採用規則は維持し、元データ・本解析CSV・xz図への一律補正は行っていない。レポートでは測定日を区別して示し、補正図を作る場合は仮定と未補正図を併記する。追加測定時には複数の共通座標を測定の前後に再測定すると、日付間・測定中の変化の検討に使える。
