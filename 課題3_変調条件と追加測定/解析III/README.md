# 2026年11月4日の条件別解析

採用した変調測定29件と位置測定4件を基準モデルでフィットし、波形・残差図と範囲依存性を出力した。自動警告なし15件、警告あり18件。変調測定の代表5条件についてモデルを比較した。

## 測定条件

固定試料位置は中央 (x=4.5, z=4.5)、Delay Timeは1秒。固定位置は電圧・周波数系列に適用し、位置系列はファイル名の座標を記録した。Sensitivity、位相、Time Constant、電圧の実効値・片振幅の区別、変調磁場の校正、途中の設定変更は未確認。Delay TimeとTime Constantは別項目として扱う。[条件記録](measurement_settings.json)

| 系列 | 件数 | 条件 |
| --- | ---: | --- |
| 電圧 | 10 | 280 Hz固定、0.5〜4.5 Vの10条件 |
| 周波数 | 20 | 1.3 V固定、20〜400 Hzを20 Hz刻み |
| 位置 | 4 | z=4.0、x=5.0、5.5、6.0、6.5 |

1.3 V・280 Hzの1件を電圧・周波数の両系列で共有する。解析に採用した33件はすべて上り掃引である。座標の単位と電圧表示方式はファイル名から確定できない。

元データは、[課題3の変調測定36件](../20261104/)と[課題2の位置測定5件](../../課題2_位置依存/測定記録/20261104/)に分けて保管している。フィット前にファイル名に `test` を含む4件を除外し、同じ変調電圧・周波数の組では末尾番号を整数として比較して最大の1件を採用する。末尾が無印なら初回扱いとし、最大番号が重複する場合はエラーで止める。20、60、120 Hzではそれぞれ `_02` を使う。位置測定には課題2の採用ルールを適用する。[選別と解析の記録](results/run_summary.json)

## 結果と判断

### 電圧依存

基準モデルの吸収FWHMは、0.5 Vの3.141 ± 0.249 kHzから4.5 Vの6.369 ± 0.225 kHzへ増加した。誤差は独立・等分散を仮定した局所的な標準誤差。信号の山谷差は0.742から増え、2.5〜3.0 Vで約2.33〜2.34、4.5 Vで2.05となった。強度の単位は記録値の単位で、感度設定の確認が必要。

高電圧側では微分ローレンツの残差に系統的な形がある。4.5 Vで有限変調Voigt型を用いると、残差RMSは基準モデルの0.477倍になり、残差の隣接相関は0.638から0.064へ減った。この条件では有限変調モデルによる波形の改善が大きい。

1.3 V・280 Hzの共鳴周波数は16.022749 MHzで、1.0 Vの16.021906 MHz、1.5 Vの16.021960 MHzから約0.8 kHzずれている。±20 kHzへの範囲変更による移動は1 Hz未満だった。この1点のずれは測定順・設定変更・位置の再現性を確認する対象とする。

[電圧依存図](results/plots/voltage_dependence.png)・[4.5 Vのモデル比較](results/model_comparison/20261104_v4.5_f280_01.png)

### 周波数依存

基準モデルの幅は40 Hzで10.65 kHz、80 Hzで5.98 kHz、200〜400 Hzでは概ね3.45〜3.76 kHzとなった。20 Hzの採用ファイルのフィット幅は18.91 kHz。信号が弱く、背景を決める範囲が短いため、定量的な幅の採用は保留する。

60 Hzの採用ファイルには大きな周期的背景があり、残差の隣接相関は約0.92である。±20 kHzへの範囲変更で共鳴中心が約5.93 kHz移動した。背景によって別の構造をフィットしている可能性があるため、中心・幅を物理量として採用する判断は保留する。

120 Hz、180 Hz、240 Hzにも共鳴から離れた領域で構造を持つ背景が見られた。原因の同定には感度・位相・時定数と取得時刻などの情報が必要。周波数ごとの強度変化の解釈には、コイル応答と検出設定の確認も必要になる。

警告付き結果は三角印で図示した。

### 位置依存

今回のz=4.0の4位置では、共鳴周波数の最大はx=5.5で16.022716 MHz。x=6.0では、刻みを細かくして取り直した `_2` を採用した。FWHMはx=5.0の3.233 kHzからx=6.5の2.678 kHzへ減り、記録信号の山谷差は増加した。x=6.5では高周波側の背景範囲が短めで、幅・強度にはモデル依存性が残る。[再測定の採用ルール](../../課題2_位置依存/測定と解析の引き継ぎ.md)

10月の測定との条件の対応は追加確認事項となる。[位置依存図](results/plots/position_dependence.png)

### 幅の分離とT2

代表5件は0.5 V・280 Hz、1.3 V・280 Hz、4.5 V・280 Hz、1.3 V・20 Hz、1.3 V・400 Hz。各々に有限変調ローレンツ、Voigt微分、有限変調Voigtを同じ測定点と直線背景でフィットした。モデル比較は準静的応答を仮定する。

電圧系列の代表3件では、変調片振幅を固定して残りの幅を再推定するプロファイルも作成した。0.5 Vでは、変調片振幅0と自由推定の約1.45 kHzで残差二乗和の違いは約1.3%だったが、ローレンツ半値半幅は約0.21 kHzから約0.57 kHzへ変わった。1.3 Vでも残差二乗和の差は約1.4%で、半値半幅は約0.56〜0.82 kHzと変わる。プロファイルは幅の交換関係を調べる診断で、信頼区間の閾値は設定していない。

このモデル依存性と未確認の校正・時定数を踏まえ、固有T2の数値は保留する。ゼロ変調への外挿には、変調電圧と磁場振幅の対応、位置・測定系の安定性を確認した上で、低電圧域のモデルと外挿範囲の評価が必要になる。

## 計算方法と出力

基準モデルは既存の課題2の `fit_segment` を再利用した。生データに対して、共鳴中心・ローレンツ半値半幅・振幅係数・背景の切片と傾きを非加重最小二乗で求める。平滑化は初期値の推定にのみ使う。出力のFWHMはこのモデルの吸収線幅、山谷間隔はその微分信号の極値間隔。

信号強度は背景を除いたフィット曲線の山谷差とし、振幅係数L0と半値半幅Gammaから 9 |L0| / (4 sqrt(3) Gamma) で求めた。標準誤差にはL0とGammaの共分散を含める。共分散は独立・等分散の残差を仮定するため、残差相関、モデルのずれ、校正や測定系の系統誤差の評価は別途必要となる。

各ファイルの全範囲に加え、基準モデルの中心から±10 kHz、±20 kHzを再フィットした。切り出した範囲で共鳴や背景が不足する場合は警告または失敗を記録した。電圧系列の±20 kHzでの幅の変化は最大約2.25%、±10 kHzでは4.5 Vで約14.2%だった。狭い窓では背景の不足とモデルのずれの両方が影響し得る。

有限変調モデルは課題1の `modulated_voigt` を再利用した。中心は測定範囲内、ローレンツ半値半幅の下限は0.02 kHz、各幅の上限は max(10 kHz, 基準半値半幅の4倍) とした。数値積分は128点から始め、点数倍増による波形差が残差RMSの0.01%以下になることを確認した。0.02 kHzの下限に達したVoigt微分の結果は境界解として比較表に記録した。

## 再実行

このフォルダで次を実行する。出力先には新しいフォルダ名を指定する。

```powershell
python -B fit_conditions.py --output results_new
python -B compare_models.py --results results_new
```

必要なライブラリはNumPy、SciPy、pandas、Matplotlib。再実行時の測定条件は `measurement_settings.json` から読み込む。`review_decisions.csv` は今回の結果に対する確認記録なので、再解析時には判断も更新する。
